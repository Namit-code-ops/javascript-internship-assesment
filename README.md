# JavaScript Internship Assessment

## About the Project

This repository contains my JavaScript internship assignments and capstone project. The purpose of these tasks is to practice JavaScript concepts and apply them through practical examples.

## Capstone Project: Product Inventory & Analytics Dashboard

The capstone project is a simple, interactive dashboard for managing product inventory and viewing basic inventory statistics.

### Features

- Add new products with their names and prices.
- View the total number of products.
- Calculate the total inventory value and average product price.
- Categorize products as Budget, Standard, or Premium.
- Search for products by name.
- View products priced under ₹5,000.
- Display a formatted inventory report.
- Validate product inputs.
- Responsive layout for different screen sizes.

### Technologies Used

- HTML5
- CSS3
- JavaScript

### How to Run the Project

1. Download or clone this repository.
2. Open `index.html` in a web browser to access the dashboard.
3. Enter a product name and price to add a product.
4. Use the **Search Inventory** button to search for a product.

The project can also be accessed through the GitHub Pages website configured for this repository.

### Project Structure

- `index.html` – Homepage that opens the capstone project.
- `capstone.html` – Main dashboard structure.
- `capstone.css` – Styling and responsive layout.
- `capstone.js` – Dashboard functionality and calculations.
- `assignment-1.html` to `assignment-6.html` – HTML files for the internship assignments.
- `assignment-1.js` to `assignment-6.js` – JavaScript files for the internship assignments.

## Learning Outcomes

Through these assignments and the capstone project, I practiced JavaScript functions, arrays, loops, conditional statements, array methods, DOM manipulation, event handling, input validation, and basic data calculations.
